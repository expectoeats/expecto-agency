✨ Animation & Motion System
Philosophy
Subtle, purposeful, corporate. No bouncy animations, no color explosions. Think how McKinsey or Infosys websites feel — smooth, confident, restrained.
Animation Rules
Default easing:         cubic-bezier(0.16, 1, 0.3, 1)
Hover transitions:      200ms ease
Entrance animations:    600ms cubic-bezier(0.16, 1, 0.3, 1)
Stagger delay:          80ms between items
Page load:              Elements fade up from translateY(24px) opacity 0 → 1
Specific Animations

Hero text: Word-by-word or line-by-line fade-up with stagger on page load
Scroll reveal: Intersection Observer — cards and sections fade up as they enter viewport (threshold: 0.1)
Stat counters: Numbers count up from 0 when section enters viewport
Navigation: Subtle background blur + border appears on scroll (not visible at top)
Cards hover: translateY(-4px) + shadow deepens + border color shifts to Brand Blue — 200ms
Buttons: Subtle scale(0.98) on click, background darkens on hover
Service icons: SVG stroke draw animation on hover
Marquee: Smooth infinite horizontal scroll for client logos (CSS animation, no JS)
CTA section: Very subtle blue tint background pulse (keyframe, 4s loop, barely visible)
Page cursor: Custom cursor dot (12px filled blue circle) + ring (28px outline, 80ms lag) on desktop only

What NOT to do

No particle effects
No 3D transforms
No color-changing animations
No text glitch effects
No loading spinners on sections
No parallax scrolling
